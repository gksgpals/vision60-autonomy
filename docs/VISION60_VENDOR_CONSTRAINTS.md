# Vision60 제조사 자료 기반 운용 제약

이 문서는 납품 자료에서 개발·시험에 직접 필요한 조건만 옮긴 것이다.
비밀번호와 장비별 인증정보는 저장소에 기록하지 않는다.

## 자율주행 안전 한계

- 운용 온도 범위는 -20~55°C이며 배터리는 65°C를 넘기지 않는다.
- 전원 투입과 최초 보행은 비교적 평탄하고 반경 2m가 비어 있는 곳에서 한다.
- 물은 최대 0.305m를 넘지 않으며 포트 마개를 모두 닫고 운용 후 건조한다.
- 52kg급 장비이므로 앞·뒤 스트랩을 잡고 2명이 운반한다.
- 경사면에서는 몸체와 적재물을 낮추고, 횡단하지 말고 경사 방향으로 이동한다.
- 단차와 장애물은 가능한 정면으로 접근한다.
- 고전압선, 고출력 안테나, 구조물 내부는 통신과 GNSS 품질을 떨어뜨릴 수 있다.

이 값들은 현재 디지털 트윈의 검증 경계이며, 실물의 실제 무게·무게중심과
센서 적재 상태를 측정하기 전에는 정밀 동역학 값으로 간주하지 않는다.

## 통신과 온보드 장치

- 로봇 직접 유선 연결은 `192.168.168.0/24` 대역을 사용한다.
- 납품 구성에는 Microhard, 외부 Wi-Fi 및 LTE 연결 절차가 있다.
- NetworkManager 연결 프로필 전환 코드는 실제 프로필 이름과 인터페이스를
  확인할 때까지 fail-closed 상태로 둔다.
- 제조사 앱은 로봇 IP와 앱 IP를 지정할 수 있고, 수동 제어권 회수와
  비상정지를 제공한다. 자율주행은 이 수동 기능보다 높은 권한을 갖지 않는다.
- 내장 RGB 카메라는 전방 2, 후방 1, 좌우 각 1대이며 HTTP H264(8080)와
  RTSP H264(4000/4001) 송출 절차가 문서화돼 있다. 실제 스트림 주소와
  카메라별 매핑은 첫날 확인한다.

## 상태·정비 경계

- HEALTH 화면에서 관절 전류, IMU, 컴퓨터 온도, 팬과 배터리를 확인한다.
- 보행 후 관절 피크 전류가 빨간색 80A 이상이면 제조사 캘리브레이션
  점검 조건이다. 운용교육 자료의 일반 상한은 100A 이하이므로 더 보수적인
  80A를 정비 개입 기준으로 사용한다.
- 영점 조정과 캘리브레이션, 배터리 교체는 작업자가 수동으로 수행한다.
  자율주행 소프트웨어가 이를 자동 실행하지 않는다.
- 충전기의 정상 충전 전류 기준은 8A이며 배터리 교체 체결 토크는 8Nm이다.
- 문제 보고에는 로봇·앱 소프트웨어 버전, 상태 화면, 임무 로그와 최초
  대응 내용을 함께 보존한다.

## 실물 연결 전 확인할 값

1. 로봇·앱·레그 펌웨어 버전과 로봇 IP를 기록한다.
2. Microhard, LTE, 외부 Wi-Fi의 실제 인터페이스와 프로필 이름을 기록한다.
3. HEALTH 상태를 캡처하고 관절 전류·컴퓨터 온도·배터리를 확인한다.
4. 적재물을 포함한 총중량, 무게중심과 Ouster 외부변환을 측정한다.
5. 수동 Take Over, E-stop, Sit, Stand, Walk를 먼저 검증한다.
